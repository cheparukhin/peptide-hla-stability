# Results page

The [public results page](https://cheparukhin.github.io/peptide-hla-stability/) and [manuscript](../reports/MANUSCRIPT.md) contain the project's main scientific results, with supplementary scores and benchmarks in [reports/REPORT.md](../reports/REPORT.md).

The HTML routes in this directory redirect to the results page so existing links lead to the same scientific account, while the repository’s `data/` and `reports/` directories preserve the source data and experimental evidence.

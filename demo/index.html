Which HLA alleles hold which peptides — and what the groove looks like

28,166 measured dissociation half-lives across 75 HLA-I alleles, with the crystallographic template for every allele. The model ranks peptides within an allele well when it has seen a close relative, and falls off a cliff when it has not — and that cliff is what the structures explain.

      Step 2

      What’s next

      Ordered by expected value per hour, not by appeal. The framework is the product — every new arm plugs into the same frozen splits and faces the same δ = 0.05 bar.

      Priority 1

      Score the test set, once

      Finish the in-flight arms and run the single scoring pass. Everything else is downstream of knowing whether the expensive arms clear 0.05.

      Machinery complete

      Priority 2

      Chimeric ESM-2 input

      The separate-embedding arm is flat, so the model never saw the interaction. A peptide–linker–groove construct is the sharpest version of the question and the biggest risk to this negative result — which is why it is worth running.

      Queued

      Priority 3

      Leave-allele-out on every arm

      The sequence arm already shows a 0.403 deficit on distant allotypes — the stratum where pretraining has the strongest prior of winning. A gain confined there would be real even if the pooled comparison stays flat.

      Contract written

      Priority 4

      Censored likelihood, done properly

      The Tobit loss was conclusively worse on ranking, but it was undertrained — its dev objective turns over around epoch 10. A predeclared re-run with the MSE stopping rule recovers almost all the ranking and halves calibration error.

      Predeclaration needed

      Priority 5

      Full structural coverage

      Boltz-2 production is the open hole. Coverage and the declared sequence fallback must be reported on the frozen cohort, not on whatever happened to fold.

      Fold in progress

      Priority 6

      Post-2016 stability data

      NetMHCstabpan trained on this exact dataset, so it can never be a comparator here. The only honest route to method parity is measurements it could not have seen.

      Data needed

      Domain knowledge is not dead yet. Foundation models do encode biology — that is the genuine insight. But encoding what we already know is not the same as extending it.

      And the most transferable finding is smaller and more useful than the headline: where you read a foundation model’s embedding from mattered more than which model produced it — reading the 34 contact positions instead of mean-pooling 182 was worth about 0.3 of Spearman, six times the worthwhile-gain bar.

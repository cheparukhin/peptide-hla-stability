# Frozen few-shot target-allele residual adaptation

This separately authorized development experiment uses only the unchanged 19,716 original-training rows, 3,587 peptide clusters, 35 actual HLA groups and five existing folds on each grouping axis. It does not read original validation/test or reserved external outcomes. Root owns Modal launches, staging, spending guards and shutdown; a metadata freeze is not a paid launch authorization.

For each allele with at least 40 distinct original-training clusters, select minimum-pair-ID representatives within clusters. Order these clusters by SHA256 of `pepstab-fewshot-v1|draw={draw}|allele={allele}|cluster={cluster_id}`, resolving ties by cluster ID. Draws are exactly 0,1,2. The first20 representatives are a maximum support set; k=0,5,10,20 use nested prefixes and exactly k measured target labels per allele. Select supports using identities only. Source data can retain sparse source alleles. No target label is used for stopping or tuning, and no other target allele's label is used in an allele's adapter.

For every HLA fold/draw, exclude the union of maximum-support clusters across target alleles from ALL source and query rows, regardless of k. For each of25 HLA/peptide joint cells, the source additionally excludes the held HLA fold and held query peptide fold. The query lies inside both held folds. Validate source/support and source/query HLA AND cluster disjointness, plus cross-allele support/query cluster disjointness. Source models never see support peptide families. Query identities remain identical at all budgets and arms within a draw. All25 cells run in each of three draws, with no dropping, replenishment, outcome-driven population choice or retry.

Source R0 and R5 models are source-only StandardScaler and ridge alpha100 with intercept, lsqr tolerance1e-5 and at most2000 solver iterations. These150 fits reuse their predictions and scaler at every target budget. R0 is existing positional peptide/HLA one-hot; R5 is the unchanged cached contact-pooled Boltz representation. Cached matrices must match canonical historical feature hashes. No embedding extraction or encoder adaptation is added.

The sequence anchor uses fresh source fits under the established original two-layer256/64 ReLU MLP recipe: both one-hot and BLOSUM encodings, natural256 batches, Adam .001, L2 1e-5/1e-3 respectively, at most300 epochs, stopping-MSE patience15, restore best weights. Within each source partition construct five balanced joint HLA/cluster stopping partitions and use exactly stop0/seed0 and stop1/seed1 per encoding. The arithmetic four-member average requires300 source MLP fits. It is a reduced historical ensemble with prior development nomination; it is not the unchanged30-member ensemble or full competitive selector. Use the raw encodings as the historical recipe does. Source stopping labels count. Report both available source labels and the actual consumed gradient/stopping union by arm; joint stopping excludes cross quadrants and can consume fewer source labels than ridge.

Each nonzero target budget fits an independent per-allele residual ridge adapter to canonical log1p outcomes minus that source model's support predictions. Use the source's scaler and divide features by sqrt(dimension), fixed alpha1 and fitted intercept; implement the centered dual solve of dimension at most20. R0 and the sequence anchor adapt on the same R0 source-scaled features; R5 adapts on its own source-scaled features. At k0 retain exact source predictions. The68 target alleles in the label-blind metadata inventory imply9180 tiny adapter solves, separate from450 source fits; no grid search is hidden in this count. Adapters must be fitted separately across query cells because their source heads/scalers differ. Support labels are the same global per-allele prefix across all five query cells and count once for that experimental draw/budget, even though reused in five adapters.

The single primary contrast is `mean_draw(score_R5_k20-score_R5_k0)` on the fixed≥20 query panel. Secondary contrasts are k5/k10 adaptation, R0 and sequence adaptation at each nonzero budget, R5−R0 and R5−sequence at each budget, and the R5−R0 adaptation-gain interaction at k20. The endpoint is median per-allele Spearman on pooled five-query-fold predictions, with original tie/constant conventions. Fix both≥20 and≥50 panels by intersecting query-count/label-variance eligibility across all three draws before reading any model scores. Average three draw scores, never predictions, and never treat duplicated queries as independent rows.

Use exactly2000 shared resamples and seed20261003. Draw from the FULL canonical cluster and actual HLA-group universes; apply common multiplicities to each draw's fixed query subset. Crossed peptide/HLA intervals are primary; peptide-only and HLA-only intervals,≥50 panels and all35 actual-HLA-group deletions are sensitivity results. HLA multiplicities replicate alleles in panel-median aggregation as well as observations. Missing label variation drops an allele identically across arms; constant predictions score0. Fail on a degenerate full-panel draw rather than replacing it. Report nominal95% intervals and97.5% intervals for the tranche's two-primary-family interpretation. Secondary comparisons are exploratory and unadjusted.

Save source scalers, model weights and stopping curves, source/support/query row IDs and label hashes, every adapter's state, predictions, exclusive attempts and completion hashes. Replay saved source predictions, saved adapter updates and final CSV numeric values. Report complete query coverage, all actual target/source budgets and the full declared comparison table. No automatic retry or widening is allowed. Root executes cells in bounded Modal workers with two numerical threads and source-bound admissions; report/bootstrap also stays on Modal.

All interpretations condition on fixed fits and the three fixed support draws. Prior development informed recipe nomination, and dimensions/parameter counts differ. Intervals omit refitting and independent assay variability. This study measures cached-feature residual adaptation to jointly unseen HLA/peptide families; it is not encoder fine-tuning, independent confirmation, a causal structural mechanism or a prospective assay-savings experiment.

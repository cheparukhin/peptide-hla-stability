## Fixed candidates

There is exactly one candidate for each of six components, on each representation. No L2, depth, epoch, feature-width, or preprocessing search is allowed.

All four MLP components use the existing NumPy MLP: one ReLU hidden layer of 64, linear scalar output, natural row minibatches, unweighted MSE on `y_log1p`, Adam learning rate .001, batch size 256, L2 .01, maximum 200 epochs, patience 15, and restore best stopping-MSE weights. Seeds are the two member seeds above. No ranking loss, allele centering, augmentation, or target transform beyond the canonical log1p label is added.

Both trees use CatBoost CPU, symmetric depth 4, exactly 512 iterations, learning rate .06, L2 leaf regularization 10, Bernoulli bootstrap with subsample .8, rsm 1, random strength 1, border count 128, thread count 2, seed equal to member seed, no writing files, and no early stopping/evaluation set. Set these parameters explicitly; save package version and complete effective parameters. Both trees receive the same gradient-StandardScaler features as `standard`. Tree stopping rows are reserved and unused: this equalizes gradient label access with the neural heads, although the trees' fixed iteration budget and MLP's adaptive stopping remain different procedures.

## Supervised leaf pipeline and reuse

For each individual fitted member define columns `(tree_index, leaf_id)` in lexicographic order for tree indices 0 through 63 and leaf IDs 0 through 15, exactly 1,024 columns. Encode one active column per tree. Unobserved leaves retain all-zero columns. Require at least 64 fitted trees and leaf IDs within range. Save the tree model hash, full column dictionary/hash, and scaler state. Apply the same member's tree and dictionary to gradient, stopping, and held rows. Never concatenate leaf columns generated by different fitted trees to form one training matrix, refit a tree before transforming held rows, infer a dictionary from held rows, or drop columns because they are absent in a fitting subset.

Tree and neural head may learn from the same gradient labels: this is a supervised feature-learning procedure. Neither stage sees stopping labels until neural early stopping, and neither sees selection/assessment labels. The leaf training representation is deliberately in-sample with respect to its upstream tree; it is not advertised as independently cross-fitted stacking. Generalization is assessed only on the untouched inner/outer held rows. The RMSE tree is fit once per member and reused for tree predictions and the leaf branch; count no second tree fit.

No historical fitted heads or predictions are reused in these 480 scientific fits. Historical representations and split machinery are reused with verified identity. This keeps all new comparisons on the same two-member schedule. Historical 30-member MSE and competitive sequence selector results may be shown as explicitly descriptive references, never as selection inputs or matched controls.

## Averaging, ranking scale, blending, and selection

Average the two predictions arithmetically for each component and each held block. All fixed-candidate inner prediction rows are excluded from both members' gradient, stopping, and transform fitting. For rank trees save raw scores. Fit one positive-affine least-squares map per representation/outer fold from its pooled raw three-fold inner predictions to the outer-fit log1p labels, using the existing `positive_affine` rule, minimum slope 1e-8. Apply that map only to the averaged final outer raw rank scores. Save map, input identity, raw final predictions, and mapped final predictions. Inner selection uses raw rank scores, never self-calibrated inner performance. Mapping is an outer-training operation and provides a common scale across final folds; transporting scale from smaller inner fits to larger outer refits is a limitation. No tree-ranker blend is included.

For each inner fold, score each component by median per-allele Spearman on the existing eligible min20 panel, using the frozen constant-prediction and tie conventions. For `blend`, evaluate `w * tree_rmse + (1-w) * standard` on the averaged clean inner predictions for tree weights `[0,.25,.5,.75,1]`. Select weight using the rule below, ordered from zero to one. Apply the selected weight to the final component averages. This adds no supervised model fits.

The rule is: compute each candidate's mean of the three inner fold scores and sample standard deviation divided by sqrt(3); identify the highest mean (ties use supplied order), then choose the first candidate in supplied order whose mean is at least `best_mean - best_SE`. Require all three scores finite. No other tolerance or held-out tie breaker is allowed. Blend weight zero is the MSE fallback.

For `hybrid_selector`, apply the same rule to the seven procedures ordered `standard`, `tree_rmse`, `tree_rank`, `blend`, `quantile_mlp`, `pca_mlp`, `leaf_mlp`. Use the chosen blend weight's three inner scores for the blend entry. The first procedure is the matched MSE fallback. Apply the selected procedure to final outer predictions. Weight selection and procedure selection both occur entirely inside outer fit. Those reused inner scores are selection diagnostics, not an unbiased assessment of the selected blend/selector; the outer assessment supplies that evaluation. No selection is repeated using min50 or pooled outer outcomes.

Save `selection.json` with every three-score vector, mean, SE, best entry, threshold, supplied order, chosen blend weight, and chosen procedure. All six fixed final components are fitted even when not selected, preserving complete comparisons rather than selectively reporting winners.

## Reporting contract and uncertainty

The sixteen primary table arms are the cross product of prefixes `R0_`, `R5_` with suffixes `standard`, `tree_rmse`, `tree_rank`, `leaf_mlp`, `quantile_mlp`, `pca_mlp`, `blend`, `hybrid_selector`. Every arm must have exactly one prediction for each canonical row, from its outer-held fold. Main endpoint is pooled-OOF median per-allele Spearman using the min20 panel. Repeat every declared contrast on min50 as a sensitivity analysis. Also report log1p MSE/MAE, per-allele scores/counts, per-fold scores, selected procedures/weights, failed/degenerate panels, fit counts, runtime and memory. These diagnostics do not trigger more fitting.

Use exactly 2,000 shared whole-peptide-cluster bootstrap draws, seed 20261003, with the existing `round2_reporting.cluster_bootstrap_scores` conventions. Fix eligible alleles from full counts/labels, reuse identical cluster draws for every arm and both panels, preserve average-rank ties and constant-prediction zero convention, and report any resample dropping alleles or becoming degenerate. Difference intervals are percentile 2.5/97.5 percentiles of paired per-draw score differences. Also report bootstrap-mean minus observed difference, because percentile intervals need not be centered on the point estimate. Do not subtract independently computed CI endpoints.

Exactly 24 ordinary contrasts per panel are prespecified: the two within-representation selector-minus-standard contrasts; each of six challengers (`tree_rmse`, `tree_rank`, `leaf_mlp`, `quantile_mlp`, `pca_mlp`, `blend`) minus matched standard on both representations (12); tree_rank minus tree_rmse on each representation (2); and R5 minus R0 for each of the eight procedures (8). The **single primary** is `R5_hybrid_selector - R5_standard` at min20. All other ordinary contrasts and min50 are secondary exploratory comparisons. One additional exploratory interaction is `(R5_tree_rank - R5_tree_rmse) - (R0_tree_rank - R0_tree_rmse)`, computed on the same four-arm bootstrap draws. This separates an observed representation-specific ranking increment from a generic ranking increment, without proving a mechanism.

Historical references, if identity-verified, use names `historical_R0_mse30`, `historical_R5_mse30`, and `historical_sequence_selector`; score descriptively outside these 24 contrasts. Explain their larger ensemble/search budgets. Never present the fresh fixed-L2 two-member standard as equivalent to the previous selected 30-member MSE procedure.

Intervals condition on already fitted, selected predictions and the reused development dataset; they omit retraining and model-selection uncertainty. All secondary intervals are nominal and unadjusted for multiplicity. This newly prespecified contrast does not turn previously examined development data into an independent confirmatory set. A crossing-zero interval is inconclusive, not evidence of equivalence. The fixed tree/MLP budgets and preprocessing change whole procedures, so conclusions cannot attribute differences solely to learner class, representation biology, or loss. No result establishes independent assay performance, assay-noise improvement, experimental validation, or benefit on unseen HLA transfer regimes.

# Project working preferences

After completing a task that changes this repository, commit the completed,
validated changes by default unless the user asks otherwise. Keep unrelated
working-tree changes out of the commit.

Run future compute-heavy jobs on Modal to avoid overwhelming the user's Mac.
Keep local work to orchestration, editing and lightweight checks. Respect the
user's explicit credit budget; use bounded resource allocations and spending
guards before launching paid jobs. Do not treat available credits as a target.

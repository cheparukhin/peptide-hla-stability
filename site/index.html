Antigen Presentation Stability:
Sequence Is All You Need?

TL;DR: We tested language-model embeddings and predicted structures against a supervised model trained on sequences. None of them won.

The two-minute version

The task

Stability is different from affinity.

Stability — how long it stays bound
t½ = ln 2 / koff
Affinity — how readily it binds
Kd = koff / kon

Our approach

  • Allele-mean (sanity floor)
  • Single sequence MLP (peptide + HLA contact residues)
  • Sequence ensemble (30 networks)
  • ESM-2 35M embeddings, alone
  • ESM-2 150M embeddings, alone
  • ESM-2 + sequence features
  • Boltz-2 structure — geometry only
  • Boltz-2 structure — confidence only
  • Boltz-2 structure — seq + geometry + confidence
  • FoldX energy + sequence

Main result

Pretrained features versus the baseline

Held-out test split, median per-allele Spearman, higher is better. Scored once, after every modelling decision was frozen. An interval crossing zero is inconclusive; a strong negative rules out the 0.05 bar.

The structural arm is conclusively worse. Its interval sits entirely below zero, and a sequence-only control through the identical pipeline beats it at every tuning setting — so the loss is the structural features, not the fit.

The ESM-2 arms are inconclusive at zero. They neither replace nor improve the baseline, and the intervals are tight enough to rule out a worthwhile gain.

We do not claim "pretraining helps." ESM-2 only ties the cheap 34-residue contact-sequence baseline. Both beat a weaker full-domain encoding by similar margins — a fact about the weak encoding, not evidence for pretraining.

One strong positive. With no retraining, the sequence model ranked 81,600 naturally presented peptides above 816,000 matched decoys — a different assay, a different biological event — at median AUROC 0.966. That is the evidence it learned real biology rather than dataset artefacts.

Next steps

Proposed experiment Explanation
ESM-C with concatenated sequences Feed peptide–linker–MHC α1α2 into ESM-C as one sequence, so each partner is represented in the context of the other. Compare against encoding them separately.
Separate embeddings + cross-attention Keep peptide and MHC embeddings separate, then add a trainable cross-attention module that connects individual peptide positions with groove positions. Compare against concatenated embeddings + a small MLP, keeping the embeddings unchanged.
Inverse-folding and energy features Score each predicted complex with ProteinMPNN peptide likelihoods and FoldX interaction energies, and test them as half-life features. Compare against the sequence ensemble, keeping the same folds and tuning budget.

Methods

The rules were fixed before any modelling. Splits are frozen 70/10/20 with peptides grouped by similarity, so no peptide within 3 substitutions appears in two splits. The primary metric is median per-allele Spearman — ranking peptides within each allele. The 0.05 bar is not a preference: below it, this benchmark cannot separate a real difference from noise.

Every arm uses the same rows, the same 30-network ensembling, and an equal tuning budget. Scores are median per-allele Spearman.

NetMHCstabpan is not used as a comparator. The published model for this task was trained on our entire dataset, including our test peptides — any score it posts here is memorisation, not prediction.

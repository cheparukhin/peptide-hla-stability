# Documentation

The [research report](../reports/REPORT.md) is the single account of scientific
results. Supporting documents answer distinct questions:

| Document | Purpose |
|---|---|
| [Statistical methods](../EVALUATION.md) | Populations, splitting, model selection, endpoints and uncertainty |
| [Data provenance](DATASETS.md) | Assay meaning, sampling, constructs and source tables |
| [Structural inputs](STRUCTURES.md) | Structure provenance and representation definitions |
| [Affinity reference](AFFINITY_REFERENCE.md) | Auxiliary affinity data and admissible joins |
| [Reproduction](DEVELOPMENT.md) | Setup, source checks and safe use of saved evidence |
| [Cached-feature inference](ROUND2_INFERENCE.md) | Portable head compatibility and prediction commands |

Numerical evidence and frozen machine-readable protocols are indexed in
[reports/README.md](../reports/README.md). They preserve the precise experiment
identity; they are not separate scientific narratives.
